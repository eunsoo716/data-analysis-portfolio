# 콜센터 콜량 수요예측

콜센터 4개 포트폴리오의 인입 콜량(CV)·응대시간(CCT)·포기율(ABD)을 **30분 단위로 예측**하는 모델을 개발했습니다. (Datathon 팀 프로젝트, 2026.03.27 ~ 04.03 / 시각화·EDA 담당, 모델링 방식은 팀 논의로 결정)

## 문제정의

콜센터는 시간대별 콜량 변동이 커 인력 배치가 어렵습니다. 정확한 수요예측으로 **적정 상담원 배치 의사결정의 근거**를 마련하는 것이 목표입니다.

## 데이터

- 콜센터 운영 데이터 (데이터 경진대회 제공)
- 일별: 2024.01–2025.12 / 30분 단위: 2025.04–06
- ⚠️ 데이터는 라이선스상 저장소에 미포함

## 분석 과정

1. 전처리 (결측치는 train 통계로만 채워 데이터 누수 방지)
2. EDA (요일·시간대·계절성·상관관계)
3. 피처 엔지니어링 (Lag·Rolling·Cyclic encoding·공휴일·staffing)
4. 포트폴리오별 LightGBM 독립 학습 (log 변환·early stopping). 30분 구간은 2025년 4~5월로 학습하고 6월로 검증해 미래 정보가 섞이지 않게 함
5. 일별 예측을 시간대 비중으로 나누는 Top-Down 방식을, 30분 구간을 직접 예측하는 End-to-End 방식으로 개선

## 결과

**1. 30분 구간 직접 예측이 Top-Down 분배보다 모든 포트폴리오에서 콜량 오차율(MAPE)을 낮춤** (2025.06 검증)

| 포트폴리오 | Top-Down | 30분 직접 예측 |
|---|---|---|
| A | 46.6% | **28.6%** |
| B | 31.3% | **22.0%** |
| C | 18.0% | **14.0%** |
| D | 20.3% | **17.0%** |

**2. 전체 시간대 오차율이 높은 것은 콜이 거의 없는 새벽 구간의 작은 오차가 비율을 키운 탓**

- 상담원이 근무하는 업무시간(8~20시)만 보면 콜량 오차율은 **7.3%(C) ~ 16.6%(A)**, 응대시간 오차율은 3.3% ~ 8.1%
- 포기율은 실제값이 0~2%로 작아 MAPE가 부풀려지므로 **RMSE**로 평가

**3. 일별 예측** (2025.08 검증): 콜량 MAPE 3.7–8.3%, 응대시간 2.4–3.4%

## 한계와 다음 과제
