# Beer Profile 소비자 세그먼트 분석 (클러스터링)

맥주 3,197종의 맛 프로파일로 **자연스러운 군집이 존재하는지, 평점이 높은 군집은 어떤 특징을 갖는지** 살펴본 비지도학습 프로젝트입니다. (대학 STAT 437 그룹 프로젝트, 2026.05.01 ~ 05.13 / **DBSCAN 파트 담당**)

> 📄 상세 보고서: [REPORT_ko.md](./REPORT_ko.md)

## 문제정의

맛 프로파일 변수만으로 내재 군집이 존재하는지, 그리고 평점이 높은 맥주는 어떤 특징을 갖는지 확인합니다. 리뷰 변수는 군집화에 쓰지 않고, 만들어진 군집을 해석할 때만 사후에 사용했습니다.

## 데이터

- Kaggle "Beer Profile and Ratings" — 맥주 3,197종 × 25개 변수
- 출처: https://www.kaggle.com/datasets/ruthgn/beer-profile-and-ratings-data-set

## 분석 과정

1. StandardScaler로 표준화
2. t-SNE로 군집 가능성 선검증 (perplexity·seed 다중 비교)
3. **DBSCAN 파라미터 탐색**: k-distance plot과 eps × min_samples 36개 설정 비교. 실루엣 점수가 가장 높은 설정은 94% 이상이 노이즈여서 쓸 수 없어, 노이즈 비율과 t-SNE를 함께 보고 **eps=1.8, min_samples=8**을 선택
4. HAC·K-Means와 교차 검증: HAC는 이상치가 섞인 상태에서 군집 2개(실루엣 0.73)가 나왔지만 이상치에 끌려간 결과였고, DBSCAN 노이즈를 제외하자 **7개 군집**으로 정리
5. 군집 특성·평점 해석 (노이즈는 오류가 아니라 별도 층으로 확인)

## 결과

| 방법 | 최종 설정 | 군집 수 | 비고 |
|---|---|---|---|
| DBSCAN | eps=1.8, min_samples=8 | 4개 | 노이즈 513종 (16%) |
| HAC (complete linkage) | k=7 | 7개 | DBSCAN 노이즈를 제외한 데이터에 적용 |
| K-Means | k=6 | 6개 | 견고성 확인용 |

- 맥주의 맛 구조는 뚜렷하게 나뉘기보다 **연속적인 스펙트럼**에 가까웠고, 쓴맛·홉 / 신맛·과일 / 바디·몰트·단맛 축이 군집을 가르는 주된 방향이었습니다.
- 군집별 평균 리뷰 점수는 **3.45 ~ 4.01**로 달랐고, 평점이 높은 군집은 쓴맛이나 도수의 강도가 가장 높은 쪽이 아니라 쓴맛과 다른 풍미가 균형을 이루는 쪽이었습니다. (관찰된 연관이며 인과는 아닙니다.)
- DBSCAN 노이즈 맥주는 평균 리뷰 점수가 3.88이지만 점수가 넓게 퍼져 있어, "이상치 = 낮은 평가"가 아님을 확인했습니다.
