# Olist 이커머스 고객 분석

브라질 이커머스 마켓플레이스 Olist의 주문 데이터를 SQL로 분석해 고객의 재구매 구조를 확인하고, 배송 지연이 고객 경험에 미친 영향을 측정한 뒤 이를 검증할 A/B 테스트를 설계한 개인 프로젝트입니다 (2026.10).

## 분석 질문
1. 고객은 실제로 다시 구매하는가, 다시 구매한다면 언제인가
2. 매출은 어떤 고객에게 몰려 있는가
3. 어떤 카테고리로 시작한 고객이 다시 돌아왔고, 두 번째 구매는 어디로 이어졌는가
4. 배송 지연은 리뷰와 재구매를 얼마나 떨어뜨렸는가

## 주요 결과
- customer_id가 주문마다 새로 발급되는 ID임을 확인하고, 같은 날 나뉜 주문을 제외해 실제 재구매율을 2.15%로 정의했습니다. 1년 안에 두 번째 구매를 한 고객도 3.33%였습니다.
- 구매액 상위 20% 고객이 매출의 53.5%를 차지했고, 매출의 69.6%는 고액 1회 고객에게서 나왔습니다.
- 예정일보다 1~3일만 늦어도 낮은 리뷰(1~2점) 비율이 10%에서 32%로 올랐고, 금액·지역·카테고리·구매 월을 통제한 로지스틱 회귀에서도 지연된 첫 주문의 낮은 리뷰 확률이 평균 26.3%p 높았습니다.
- 재구매 감소는 유의하지 않았습니다(p = 0.18). 표본 수 계산으로 이 차이를 확인하려면 그룹당 약 17,000명이 필요해, 지연 고객 3,671명으로는 판단할 근거가 부족했던 것으로 정리했습니다.
- 지연 급증 시기에 배송 예정일을 더 길게 안내하는 A/B 테스트 설계안을 작성했습니다(실행 전 단계). 지연 주문의 절반이 개선된다는 가정으로 기대 효과를 잡았고, 1차 지표는 낮은 리뷰, 가드레일은 구매 전환율·취소율이며 그룹당 약 6,000명·2개월이 필요한 것으로 계산했습니다.

## 분석 단계
| 단계 | 내용 | 주로 사용한 방법 |
|---|---|---|
| 1 | 데이터 구조와 분석 기준 확인 | GROUP BY, CASE, 윈도우 함수 |
| 2 | 분석용 테이블 생성 | CTE, JOIN, ROW_NUMBER |
| 3 | 코호트 재구매 분석 | DATE_TRUNC, DATE_DIFF, CASE 피벗 |
| 4 | 고객 세그먼트와 매출 집중도 | NTILE, 누적 합계 윈도우 함수 |
| 5 | 첫 구매 카테고리와 카테고리 이동 | ROW_NUMBER, LEAD, HAVING |
| 6 | 배송 지연의 영향 | CASE 구간화, 로지스틱 회귀(statsmodels) |
| 7 | 결론과 제안 | |
| 8 | 후속 실험(A/B 테스트) 설계 | 표본 수 계산, SRM 점검, 두 비율 z검정 |
