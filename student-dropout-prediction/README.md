# 학생 학업 중도이탈 예측 (Student Dropout Prediction)

학업을 중도에 포기할 가능성이 높은 대학생을, 도울 수 있을 만큼 일찍 찾아낼 수 있는지 살펴본 분류 분석입니다. (Illini Data Science Club 6명 팀 프로젝트, 2025.08 ~ 2026.05 / **전처리·EDA·모델링·결과 정리를 통계 전공 팀원 1명과 함께 담당**)

## 문제정의

이 데이터에서는 대학생 3명 중 1명(32.1%)이 중도이탈했습니다. 도울 수 있을 만큼 일찍(1학기 말) 위험한 대학생을 찾아낼 수 있는지, 그리고 상담 인원이 한정될 때 누구에게 먼저 연락해야 하는지를 확인합니다.

## 데이터

- UCI Machine Learning Repository, "Predict Students' Dropout and Academic Success" (포르투갈 한 대학 학생)
- 학생 4,424명 × 36개 변수, 중도이탈 32.1%
- 이 저장소에는 데이터 파일을 포함하지 않았습니다. UCI에서 내려받아 `data.csv`로 노트북과 같은 폴더에 두면 실행됩니다 (구분자 `;`).

## 분석 과정

| 단계 | 내용 | 핵심 결과 |
|---|---|---|
| Part 1 | 2학기 정보를 포함한 8개 모델 비교, XGBoost 선택, SHAP 해석 | 정확도 88%, F1 0.81. 단, 2학기 정보가 포함되어 실제 조기 경보에는 쓸 수 없는 점수 |
| Part 2 | 1학기 말까지의 정보만 사용, 반복 교차 검증, SMOTE, 3분류 | ROC-AUC 약 0.91, F1 약 0.77. 로지스틱 회귀가 XGBoost·LightGBM과 비슷. SMOTE는 추가 이점 없음. 3분류 Macro F1 약 0.69 |
| Part 3 | 중도이탈 학생을 군집으로 나눠 유형 확인, 모델의 사각지대 확인 | 4가지 유형(학기 중 이탈 32%, 채무·미납 18%, 장학금 수혜 9%, 학업 중간 40%). 장학금 수혜형·학업 중간형은 위험 상위 20%에 29~32%만 포함 |
| Part 4 | 상담 인원이 정해졌을 때 위험 순서로 연락하는 시나리오, 단순 규칙과 비교 | 아래 결과 참고 |

## 결과

- **데이터 누수 발견**: 처음 모델에서 가장 강한 변수는 2학기 성적과 이수 학점이었습니다. 2학기에 시험을 한 번도 보지 않은 학생이 중도이탈 학생에서 약 21%, 나머지에서 3~4%여서, 중도이탈이 이미 진행된 결과를 읽는 데이터 누수로 판단했습니다.
- **1학기 말 정보로 재설계**: 반복 교차 검증으로 평가한 결과 ROC-AUC 약 0.91, F1 약 0.77입니다. 점수는 내려가지만 실제로 쓸 수 있는 값입니다.
- **연락 범위에 따른 trade-off**: 위험 순서대로 연락할 때 적중률(연락한 학생 중 실제 중도이탈 비율)과 재현율(전체 중도이탈 학생 중 연락이 닿은 비율)은 다음과 같습니다.

| 연락 대상 | 적중률 | 재현율 | (비교) 이수 학점이 적은 순 규칙의 적중률 |
|---|---|---|---|
| 위험 상위 20% (885명) | 92% | 57% | 78% |
| 위험 상위 30% (1,327명) | 80% | 75% | 71% |

범위를 넓히면 더 많이 찾는 대신 적중률이 낮아집니다. 어디까지 연락할지는 모델이 아니라 학교가 정할 결정의 문제입니다.

## 한계

- 데이터에 상담·개입 기록이 없어 연락이 중도이탈을 실제로 줄이는지는 알 수 없습니다. 이 분석이 보여 주는 것은 예측이 얼마나 맞는지와 누구를 놓치는지입니다.
- 등록금·장학금 변수가 1학기 말에 알려지는 정보인지 측정 시점이 불분명합니다.
- 한 대학의 한 시기 데이터입니다.
- Part 1의 점수는 데이터를 한 번만 나눠 평가해 Part 2~4(반복 교차 검증)와 직접 비교할 수 없습니다.
